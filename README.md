# cake-zone

Cake Zone Qatar — Luxury Gifting & Celebration Boutique. Handcrafted artisan cakes, fresh floral arrangements, luxury Swiss chocolates, and premium hampers in Doha, Qatar.

## Tech Stack
- React 18
- Vite
- Custom CSS with responsive layouts & typography (Merriweather, Lora, Redaction 10)
- WhatsApp direct concierge integration

## Development
```bash
npm install
npm run dev
```

## Production Build
```bash
npm run build
```
